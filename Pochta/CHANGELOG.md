# История версий «Хватит.Почты»

Версия = `versionName` в `app/build.gradle.kts`; `versionCode` растёт на 1 с каждой сборкой,
которая уходит на устройства. Каждая версия — тег `vX.Y.Z` в git, APK — в `../releases/HvatitPochta-<версия>.apk`.

Правило: любая пересборка, которую ставим на телефон/отдаём, — новая версия
(исправление — третья цифра, новые функции — вторая).

## 0.2.1 — 15.11.2026 (versionCode 3)

- Подпись под иконкой на рабочем столе — «ЯКП» (полное «Хватит.Почта» не влезало и переезжало).
  Имя приложения в настройках, списке приложений и публичное название — по-прежнему «Хватит.Почта».

## 0.2.0 — 15.11.2026 (versionCode 2)

- Название «Хватит.Почта».
- Своя иконка: адаптивная (Android 8+, конверт помещается в любую маску лаунчера), монохромный слой для
  тематических иконок Android 13+, PNG для Android 5–7; 512×512 для магазина — `branding/play-icon-512.png`.
  Всё собирается скриптом `branding/make_icons.py` из `branding/icon-source.png`.
- Значок уведомления — белый силуэт конверта (был системный значок), салатовый акцент.

## 0.1.0 — 15.11.2026 (versionCode 1)

Первый прототип. Проверено на Huawei GRL-LX9 (Android 12, WebView 114): вход, чтение, отправка писем.
- Две вкладки — веб-версии Яндекс Почты и Mail.ru в WebView; ссылки на чужие сайты — во внешний браузер;
  вложения качаются через DownloadManager с cookies, файлы прикрепляются системным выбором.
- Реклама: сетевой фильтр (Директ, РСЯ, Метрика, Adfox, myTarget, счётчики Mail.ru) и CSS по сервисам.
  Убраны: «Почта лучше в приложении» (крестик нажимается сам), «Открыть в приложении» внизу, места под Директ,
  «Почта в RuStore» (удаляется из DOM — её `<style>` запирал прокрутку бокового меню Mail.ru),
  «Приложение … / Перейти / Скачать» в боковых меню обоих сервисов, баннеры Mail.ru.
- «⋮ → Скрыть элемент…»: свой блок касанием, «Шире» — родитель; правила по сервису, «Вернуть скрытые».
- Уведомления о новых письмах: опрос раз в 15/30/60/180 мин (JobScheduler) внутренних счётчиков веб-почты
  с cookies из WebView. Яндекс — `app-badge-counter`; Mail.ru — все ящики сессии, по каждому только «Входящие»
  (API папок мобильной версии; общий `mail_cnt` считает соцсети и рассылки). Отдельное уведомление на ящик.
  Защита от двойного прогона (Huawei запускал задачу дважды в секунду).
- Число непрочитанных на вкладках; тихая проверка при возврате в приложение.
- Mail.ru: «⋮ → Скрывать детские ящики» в переключателе ящиков (по умолчанию скрыты).
- «⋮ → Журнал»: что ответили проверки и сколько запросов заблокировано.
