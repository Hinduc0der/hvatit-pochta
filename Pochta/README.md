# Почта (прототип)

Лёгкая обёртка над веб-версиями Яндекс Почты и Mail.ru: без рекламы, с уведомлениями о новых письмах.
Kotlin, без AndroidX, вёрстка кодом, Android 5.0+ (minSdk 21). APK ~0,9 МБ.

**Зачем так, а не IMAP:** с 2026 года Яндекс (для доменов на бесплатном тарифе) и Mail.ru (для всех)
пускают IMAP/POP3/SMTP — в том числе через OAuth — только с платной подпиской. Веб-версия бесплатна,
поэтому приложение — это браузер, который открывает только почту.

## Как устроено

| Файл | Что делает |
|---|---|
| `Svc.kt` | два сервиса: стартовый адрес, «свои» домены (остальные ссылки — во внешний браузер) |
| `MainActivity.kt` | две вкладки-WebView, загрузки вложений (DownloadManager с cookies), выбор файлов, «Скрыть элемент», меню |
| `AdBlock.kt` | 1) сетевой фильтр по доменам/путям (`shouldInterceptRequest` → пустой ответ); 2) CSS-скрытие |
| `Counter.kt` | число непрочитанных внутренними запросами веб-почты с cookies из WebView |
| `Checker.kt` | периодическая проверка (JobScheduler, 15/30/60/180 мин) и уведомления |
| `Store.kt` | настройки, последние счётчики, пользовательские правила скрытия, журнал |

### Счётчики непрочитанных (проверено в браузере 15.11.2026)
- **Яндекс:** `POST https://mail.yandex.ru/web-api/models/liza1?_m=app-badge-counter`,
  тело `{"models":[{"name":"app-badge-counter","params":{}}]}` → `models[0].data.counters.unread`. ckey не нужен.
- **Mail.ru:** `GET https://portal.mail.ru/NaviData?mac=1` → `data.mail_cnt` (строка). Этим шапка портала рисует счётчик.
  `data.list` — все ящики сессии (добавляются штатно: меню → «Добавить почтовый ящик»); для каждого
  отдельный запрос с `&Login=<адрес>`. Но `mail_cnt` — сумма по ВСЕМ папкам (соцсети, рассылки, чеки:
  2301 против 107 во «Входящих»), поэтому число каждого ящика берётся из API мобильной версии:
  `POST touch.mail.ru/api/v1/tokens?email=E` → `body.token`, затем
  `GET touch.mail.ru/api/v1/folders?htmlencoded=false&email=E&token=T` → папка `type=inbox`, `messages_unread`.
  Не вышло — откат на `mail_cnt`. Проверено 15.11.2026 на двух ящиках одной сессии.

### Найденная реклама на мобильных версиях (15.11.2026, Huawei GRL-LX9, WebView 114) — `Svc.css`/`closeButtons`
- Яндекс: попап `PopupAggressivePromoApps` (жмём крестик), `FloatingButton`/`BottomPageBanner` «Открыть в приложении»,
  `.direct` — места под Директ между письмами (содержимое уже режет сетевой фильтр).
- Mail.ru: `.tp-1-overlay` «Почта в RuStore» (удаляется из DOM целиком: внутри свой `<style>` с
  `html, body { overflow: hidden !important }` — иначе не прокручивается боковое меню), `div#banner188`,
  `promo--open-in-app_*` «Приложение Почты / Скачать» в меню.
- Яндекс, меню: `.sidebarPromo` «Приложение Яндекс Почта / Перейти».
- Mail.ru: детские ящики в переключателе — `.multiauth__item_child`; прячутся переключателем
  «⋮ → Скрывать детские ящики» (по умолчанию включено).

Это недокументированные API. Сломаются — почта во вкладке продолжит работать, отвалятся только уведомления;
смотреть «⋮ → Журнал».

Пока приложение открыто, счётчик берётся ещё и из заголовка страницы («26 · Входящие — Яндекс Почта»),
и это число запоминается как «уже видел» — фоновая проверка уведомит только о письмах сверх него.

### Реклама
Сеть: Директ/РСЯ/Метрика/Adfox, myTarget/счётчики Mail.ru — список в `AdBlock.hosts`.
Часть рекламы Яндекс отдаёт со своего же `mail.yandex.ru` под шифрованными путями — её режет только CSS.
Для этого **«⋮ → Скрыть элемент…»**: коснуться блока, «Шире» — взять родителя, «Скрыть». Правило
(CSS-селектор) запоминается для сервиса, «Вернуть скрытые» сбрасывает. Удачные правила потом стоит
перенести во встроенный `AdBlock.BASE_CSS`. В отладочной сборке включён `chrome://inspect` — удобно подбирать селекторы с ПК.

## Сборка и версии
```
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot
gradlew assembleDebug      (отладка: chrome://inspect включён)
gradlew assembleRelease    (выпуск)
```
Репозиторий — папка `почта/`. **Любая сборка, которая ставится на устройство или отдаётся, — новая версия:**
поднять `versionCode`/`versionName` в `app/build.gradle.kts`, запись в `CHANGELOG.md`,
APK в `../releases/Pochta-<версия>.apk`, коммит и тег `v<версия>`. Ключ подписи — `../signing/`
(`keystore.properties` + `.jks`, в git не лежит; без него релиз подписан отладочным ключом).

## Ограничения прототипа
- Уведомления — опрос, не push: Android откладывает задачи в Doze, реальная задержка до ~15–60 мин.
  На Huawei/Xiaomi приложению нужно разрешить автозапуск и работу в фоне, иначе система убивает задачу.
- Скачивание вложений через `blob:` не поддержано (покажет сообщение).
- В уведомлении только число писем, без отправителя/темы.
- Иконка и цвета — заглушки.
