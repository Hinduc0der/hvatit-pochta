# Хватит.Почта

Лёгкий Android-клиент для **Яндекс Почты** и **Mail.ru** без рекламы — с уведомлениями о новых письмах.

С 2026 года Mail.ru (для всех ящиков) и Яндекс (для доменов на бесплатном тарифе) открывают IMAP/POP3/SMTP
сторонним программам только по платной подписке — даже через OAuth. Веб-версии остаются бесплатными,
поэтому приложение не изобретает свой протокол: это браузер, который открывает только почту, вырезает
рекламу и зазывания «скачать наше приложение» и сам проверяет, не пришло ли письмо.

- Две вкладки: Яндекс и Mail.ru, несколько ящиков Mail.ru в одной сессии
- Реклама режется на уровне сети и вёрстки; любой оставшийся блок можно скрыть касанием
- Уведомления о новых письмах во «Входящих» — отдельно по каждому ящику
- Пароли и письма никуда не уходят: вход — на страницах самих сервисов, проверка идёт напрямую к ним
- ~0,9 МБ, Android 5.0+, без Google-сервисов, без сторонних библиотек

> Неофициальное приложение. Не связано с ООО «Яндекс» и VK. Пользуется теми же адресами, что и веб-версии
> почты в браузере; если сервисы их поменяют, уведомления могут перестать работать до обновления.

## Сборка

JDK 17, Android SDK.

```
cd Pochta
gradlew assembleRelease
```

APK — `Pochta/app/build/outputs/apk/release/`. Без `signing/keystore.properties` релиз подписывается
отладочным ключом.

Как устроено (счётчики, блокировка, найденные селекторы) — [`Pochta/README.md`](Pochta/README.md),
история версий — [`Pochta/CHANGELOG.md`](Pochta/CHANGELOG.md).
